# 性能包絡の再検証（修正後）

`envelope_001` と同一グリッド（native／jev × 離水着水 ×
Hs=0.3,1.5,2.5,3.5 × 横風-5,-3,3,5 × シード9500–9502、全192試行）を
引き起こし速度スケール＋波浪ロールばね修正後に再実行した。
`HAMA_OUTPUT` を振って5分割で実行し、`envelope.json` に統合した。

```bash
HAMA_PILOT=native,jev HAMA_HS=0.3,1.5,2.5,3.5 HAMA_WIND_Y=-5,-3,3,5 \
HAMA_SEEDS=9500,9501,9502 HAMA_JEV_CALIBRATOR=results/flight_jev_002/calibrator.npz \
python3 results/envelope_002/sweep.py
```

## 結果：191/192

Hs≤2.5 は 144/144。Hs=3.5 は 47/48。唯一の失敗：

- native 着水 Hs=3.5、横風 -5、シード9502：time_limit。
  波底（eta=-2 m）に沿って滑空し30秒内に接水せず。
  修正前のコードでは同条件で接水成功するが、要因切り分けの結果、
  成否を分けたのはサーボ権限（5%凍結 vs 全権限）による
  波位相の当たり方の差であり、系統的な優劣ではない。
  旧権限に戻すと Hs=6 のバンク発散が復活するため現状を維持する。

native と jev の差はなし（内側が同じ内蔵制御）。
運用包絡 Hs≤3.5・|横風|≤5 m/s の主張は維持する。
単一の波位相依存スキマーは包絡の角の既知の残りとする。
