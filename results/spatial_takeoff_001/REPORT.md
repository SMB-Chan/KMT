# 空間離水RL（400エピソード）

ハブ 0.90 m 採用後、ダメージなし空間環境で離水を学習した。
学習シード 8000–8399、検証 18000–18019（環境）、最終評価は車両 9500–9504×横風±3。
モデル選択は検証の成功数、同数なら平均報酬。最終の10条件は選択に使っていない。

学習は Hs=0.3 m、方向性海面、風 (0, 3, 0) m/s、突風 RMS 0.5 m/s。
採用は window 成功率が最大の `takeoff_best_policy.npz`（検証も最終より高報酬）。

## 結果

| 評価 | 成功 |
|---|---|
| 学習中（400 ep） | 0/400 |
| 検証環境 20 ep | best 0/20、final 0/20 |
| 車両10条件・4軸生指令 | 0/10 |
| 車両10条件・推力ピッチ＋横補助 | 10/10 |

4軸生指令では 9/10 が高度・速度は離水相当（z≥7 m、Vx≥13 m/s）だが |y| が 28–50 m で横条件を外す。1/10 は低速停滞。
横補助はバンク・ラダーだけを進路維持に置き換える。既存の縦RL＋横補助は 7/10、内蔵制御は 10/10。

400エピソードでは横運動を獲得できなかった。成功判定は |y|<10 m 等を含むため、環境成功も 0 のまま。
これは空間方策の完成ではなく、縦操縦を空間環境で再学習した参考結果である。
